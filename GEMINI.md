# Google Antigravity Workspace Instructions

Follow the shared requirements in `AGENTS.md`. Before coding, inspect `SKILLS-INDEX.md`, select the relevant skills, and read their complete canonical `skills/<name>/SKILL.md` files.

Antigravity discovers project skills from `.agents/skills/` and rules from `.agents/rules/` in supported versions. The canonical source is `skills/`; synchronize native copies with `scripts/sync-skills.ps1`. Do not assume a skill is loaded merely because a file exists; verify discovery in the installed Antigravity client.
