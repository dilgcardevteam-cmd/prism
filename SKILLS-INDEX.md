# Skills Index

## Required skill-selection workflow
Before coding:
1. Parse the request into task types (feature, bug, schema, UI, security, import/export, performance, testing, deployment).
2. Select skills below using their descriptions; multiple skills can apply.
3. Read the full selected `SKILL.md` files, not just this index.
4. Tell the user briefly which skills are relevant when useful; do not claim a skill was loaded if it was not read.
5. If no skill applies, proceed using `AGENTS.md` and consider proposing a new skill after the task.

Canonical skill files live under `skills/<name>/SKILL.md`. Assistant-specific copies are generated by `scripts/sync-skills.ps1`; edit the canonical files only.

## Skill improvement workflow
1. Capture a repeated user correction, recurring task, or proven successful workflow.
2. Decide whether it is broadly reusable or belongs in a specific project's `AGENTS.md` (project-only rules stay in the project).
3. Search existing skills for overlap; extend the best match instead of duplicating.
4. Draft a concise, actionable instruction with trigger/use cases, prerequisites, steps, safety, and validation.
5. Ensure the skill's frontmatter `name` matches its folder and its `description` explains when to invoke it.
6. Test it against at least one realistic task; remove vague or contradictory rules.
7. Update this index and README if the skill is added, renamed, or materially changed.
8. Review the diff, version-control the change, and synchronize copies.
9. Do not store secrets, private data, temporary incidents, or unverified assumptions in skills.

## Verification checklist
- [ ] Skill folder and `SKILL.md` exist; name is lowercase/hyphenated.
- [ ] YAML frontmatter parses and includes `name` and `description`.
- [ ] Description identifies task triggers and intended use.
- [ ] Instructions are specific, ordered, and testable—not empty boilerplate.
- [ ] No contradictory rules or duplicated baseline policies.
- [ ] Skill is listed in this index.
- [ ] Canonical copy is committed; sync destination is correct.
- [ ] AI can identify/read the skill in the target assistant.
- [ ] A realistic test prompt results in appropriate skill use.
- [ ] AI reports what it actually inspected and tested.

For authoring, review, conflict handling, and cross-project synchronization, see `SKILLS-MANAGEMENT.md`.
